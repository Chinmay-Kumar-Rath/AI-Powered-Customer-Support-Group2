title: Security software disabled unexpectedly
category: Security
keywords: security, endpoint protection, malware
---
Question: What should I do about security software disabled unexpectedly?

Suggested answer: Follow the safe first-line checks below and use only organization-approved tools and procedures.

Steps:
1. Do not continue sensitive work on the affected device.
2. Record the protection status, device name, and time observed.
3. Do not install replacement security tools without authorization.
4. Contact the security or endpoint-management team.
5. Follow authorized remediation and verification steps.

Escalate if: the issue continues, affects multiple users, or involves suspected compromise, possible data loss, or an unsafe condition.

Safety note: These are general first-line checks. Do not open equipment, alter firmware, change corporate network or security settings, bypass MFA, disable endpoint protection, or modify production data without authorization.
