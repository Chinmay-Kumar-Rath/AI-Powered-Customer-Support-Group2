Question: What should I do if VPN is blocked by a local firewall?

Suggested answer: Confirm ordinary internet access works without the VPN. Test an approved alternate network to isolate local Wi-Fi/router issues. Check that the network adapter is enabled and system date/time are correct. Restart and reconnect using the organization's approved VPN client and profile. If it connects but resources remain unavailable, record the exact error, time, network type and client logs for IT. Do not disable security controls or install an unapproved VPN. Ports, docks and peripherals

Steps:
1. Follow the safe first-line checks described in the suggested answer.
2. Record any exact error, status light, diagnostic code, or observed symptom.
3. Stop and request authorized support if the issue persists or the check is unsafe.

Escalate if: the issue continues, affects multiple users, or involves physical danger, suspected compromise, or possible data loss.

Safety note: These are general first-line checks. Do not open equipment, alter firmware, change corporate network or security settings, bypass MFA, disable endpoint protection, or modify production data without authorization.
